# ADR-004：参考驱动的 Relay Signal OS 界面

> 状态：Accepted
> 日期：2026-08-29
> 决策范围：完整交互式 Relay Demo 的视觉、动效与信息架构

## 背景

Calm Tech Glass 已完成多角色、移动端和状态清晰度，但用户认为整体完成度和
辨识度不足。用户指定本地 `NEON LOOP OS / V2` 页面及其最终设计任务作为
参考，希望 Relay 在整体风格、动效和 UI/UX 感受上达到非常接近的质量。

参考页的完成度不是来自单一颜色或玻璃效果，而是以下关系共同形成：

1. 悬浮系统导航、二级状态栏、网格和编号构成严格骨架；
2. 大字号黑色标题与一个非对称主视觉形成第一视觉重心；
3. 青色、紫色和酸绿色只在状态、能量和主操作中出现；
4. 动效分别承担导航、发现、输入反馈与完成奖励，不做全屏无意义漂浮；
5. 桌面同时展示多个层级，移动端重新编排优先级而不是等比缩小。

## 决策

采用 **Relay Signal OS**。桌面工作区使用顶部悬浮模块导航替代普通左侧栏，
下方保留本地同步、当前模块和用户视角状态。总览首屏使用大标题与原创“责任
信号轨道”主视觉，表现事项在发起者、受邀者和当前负责人之间的流动。

全局交互语法包括：

- 路由切换时出现一次短促信号扫描；
- 精细指针设备使用不遮挡点击核心的信号光标；
- 主按钮和明确可点的任务卡有低幅磁吸/扫描反馈；
- 负责人变化使用轨道脉冲，完成使用低频确认反馈；
- 背景只保留慢速、低对比网格和局部光场；
- 触摸设备关闭自定义光标，减少动态模式关闭扫描、视差和环境动画。

原创转换边界：不得复制 PICO、NL/OS 品牌、活动文案、生成图、游戏模块或
原项目专属素材。可以迁移布局节奏、材质关系、动效语法、状态密度和组件比例。

## 不变边界

- 仍为本地确定性 React Demo；
- 仍使用同一 reducer、localStorage 与 BroadcastChannel；
- 不增加远程字体、远程图片、运行时 AI、数据库、认证或部署；
- 状态和负责人必须在无颜色、无动画时仍可理解；
- `/demo` 与公开协作路由继续通过原有验收。

## 验收

1. 1440×900 首屏能在三秒内看出产品、当前用户、下一步和主操作；
2. 375×812 不横向溢出，视角切换、导航和新建操作始终可达；
3. 总览、事项、协作、关系人、动态、设置和产品故事共享同一视觉系统；
4. 路由扫描、磁吸、责任信号和自定义光标均有 reduced-motion/触摸降级；
5. 四角色数据流、CRUD、同步、离线和十连跑不因视觉重构回归；
6. 截图与代码中不包含参考项目的品牌、角色或专属素材。
